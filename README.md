# Enterprise Multi-Branch Network Infrastructure

## Overview
This project demonstrates an enterprise-level multi-branch network using Cisco Packet Tracer. The network connects Head Office, Branch Office 1, and Branch Office 2 using OSPF dynamic routing.

## Technologies Used
- Cisco Packet Tracer
- OSPF
- VLAN
- DHCP
- Routing & Switching
- TCP/IP

## Features
- Multi-Branch Connectivity
- OSPF Dynamic Routing
- VLAN Segmentation
- DHCP Configuration
- WAN Serial Connections
- Inter-Branch Communication

## Branch Networks

| Department | Network |
|------------|----------|
| HR | 192.168.10.0/24 |
| Admin | 192.168.20.0/24 |
| Sales | 192.168.30.0/24 |
| Support | 192.168.40.0/24 |

## Devices Used
- Cisco 2811 Routers
- Cisco 2950 Switches
- PCs and Laptops

## Outcome
Successfully implemented a scalable enterprise network with OSPF routing and communication between multiple branches.
